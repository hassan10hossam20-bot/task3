بحث عن لغة الجافا اسكربت (JavaScript)

إعداد الطالب: [حسن حسام علي حسن ]
الفرقة : التانيه

مقدمة

تعتبر لغة الجافا اسكربت (JavaScript) من أهم لغات البرمجة اللي بنستخدمها في تطوير الويب حالياً. لما بنعمل أي صفحة إلكترونية، بنستعمل HTML عشان نبني الهيكل الأساسي، وCSS عشان نظبط الشكل والألوان، بينما بنستخدم JavaScript عشان نخلي الصفحة تفاعلية وحية وتستجيب للي بيعمله المستخدم.

أهمية لغة JavaScript

اللغة دي بتشتغل أساساً في المتصفح عند المستخدم (Client-side)، وده بيخلينا نعمل حاجات كتيرة زي التحقق من البيانات اللي بيكتبها في النماذج، وعرض الرسائل، وتغيير شكل الصفحة من غير ما نحتاج نعمل إعادة تحميل (Refresh) للموقع كل شوية.

اللغة مهمتها في الصفحة
HTML بناء الهيكل والعناصر الأساسية.
CSS التنسيق والمظهر والألوان.
JavaScript إضافة التفاعل والحركة والوظائف.

الخاتمة

في النهاية، ممكن نقول إن أي موقع ويب حديث مبيخلوش من الجافا اسكربت، لأنها بتدي للموقع روح وتخلي تجربة المستخدم أسهل وأفضل بكتير.
